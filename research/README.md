# Research notes — how to read them

**Evidence limits of this run (4 Nov 2026):** the research session could run web *searches* (which return short
summaries) but could not open most pages (only a few hosts were reachable). So:

- **[S]** = claim backed by a search-result summary; the link is given. Not verified on the original page.
- **[R]** = *our recipe* — a starting parameter set we chose and tuned by eye. It is **not** a measured copy of any
  named brand's ad. Where a brand is named it is as a style reference only.
- **[U]** = unverified / opinion / could not confirm. Treat as a hypothesis.

Frame counts assume 30 fps unless said otherwise.
Nothing in `research/` claims to have frame-measured an Apple/Linear/Stripe ad; that would need watching the videos.
